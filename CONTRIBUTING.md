# Contributing to RED-BITB

Thank you for your interest in improving RED-BITB! This is an educational project aimed at security awareness. We welcome contributions that make the tool more modular, fix bugs, or add new conceptual templates.

By contributing to this project, you agree that your work will be licensed under the **GNU General Public License v3.0 (GPL-3.0)**.

## ⚠️ Absolute Rule: Keep it Educational

This tool is strictly for authorized research, authorized security assignments and defense education. Try to keep templates generic and conceptual. But if possible it is allowed to make it better for the tool.

## 🚀 How to Contribute

### 1. Adding New Components
If you want to add a new browser header or login interface:
1. Create a generic HTML template.
2. Ensure it fits the placeholder system used in `RED-BITB-Generator.py`.
3. Name it using the correct prefix (`header_yourbrowser.html` or `login_yourservice.html`).
4. Place it in the `Generator/componenten/` folder.

### 2. Reporting Bugs or Requesting Features
- Open an **Issue** on GitHub.
- Describe the bug clearly or explain why the feature benefits the educational goals of the project.

### 3. Submitting Code Changes (Pull Requests)
1. **Fork** the repository to your own GitHub account.
2. Create a new branch for your feature or fix:
   ```bash
   git checkout -b feature/amazing-feature
   ```
3. Commit your changes with clear, descriptive commit messages.
4. Push your branch to your fork:
   ```bash
   git push origin feature/amazing-feature
   ```
5. Open a **Pull Request (PR)** against our `main` branch.

## 🛡️ Code of Conduct
Please maintain a professional, respectful, and collaborative environment. We are here to learn and build defensive awareness together.
